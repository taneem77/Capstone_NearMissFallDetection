1. Clinical Need & Perturbation Scenario

Theoretical & Biomechanical Model • Maki & McIlroy Involuntary Grasp Arc
Currently showing: Elderly Care | Normal Walking

Single-sensor inertial detectors cannot differentiate purposeful cane strikes from balance loss. A sudden stumble triggers an involuntary grasp reflex within 100–180 ms. Sensing this dual-domain coincidence prevents false alarms.

Elderly Assisted Living Domain:

User walks outdoors. An uneven pavement lip induces an unexpected trip. Dual-domain sensing flags the near-miss in the pre-impact phase, alerting caregivers and logging the event to track progressive frailty.

8. Methodological & Technical Limitations

Academic Critique • Phase-2 Engineering Roadmap
Currently showing: Limitations Matrix & Phase-2 Roadmap

Rigorous engineering requires transparent acknowledgment of experimental and hardware boundaries.

Table 5: Comprehensive Limitations Matrix & Phase-2 Remediation Roadmap
Limitation Domain Current Phase-1 Boundary Phase-2 Planned Remediation
Sensor Placement Divergence K-Fall benchmark IMU was affixed to the lower back (L5 sacrum), not the cane shaft. Cane swing dynamics differ from lumbar center-of-mass motion. Deploy physical ESP32 cane prototypes across 15 geriatric cane users to collect dedicated naturalistic walking telemetry.
Grip Force Ground Truth K-Fall dataset lacks handle grip sensors. Palmar dynamics on K-Fall trials are synthesized using verified somatic reflex equations. Instrument cane handle with multi-zone capacitive pressure matrix to capture individual finger pressure distribution.
Volunteer Demographics All K-Fall data collected from healthy young adults (mean age 24.2 years) in laboratory trip-hazard harness rigs. Validate on target geriatric population (>65 years) and post-stroke individuals exhibiting asymmetric hemiplegic gait patterns.
Hardware Enclosure & Power Breadboard prototype tethered via USB cable to laptop; no onboard LiPo battery or water-resistant enclosure. Custom PCB design with integrated TP4056 LiPo charger, 3.7V 850mAh battery, and IP54 3D-printed handle enclosure.
Edge TinyML Deployment Random Forest runs in Python on laptop; ESP32 currently streams raw I2C packets over Serial/Wi-Fi. Quantize Random Forest model to C++ header array via TensorFlow Lite for Microcontrollers (TFLM) running on ESP32 dual core.
Defensible in Viva: Acknowledging these boundaries proves scientific honesty and establishes a clear path for Phase-2 work.
